Here's my completed technical assessment.

For reference, here's the [Figma file](https://www.figma.com/design/uJuB49pByqL3ZifGnh4w8c/Stitch-TPs-Test?node-id=0-1&t=8zgoJregF34HLLo4-1) that was assigned, as well as the [brief](https://docs.google.com/spreadsheets/d/1M7ov8JpcwORnVN9HDNkGVF04b7_cacJR/edit?usp=sharing&ouid=104146609258034938022&rtpof=true&sd=true).

Here are some quick notes on what's inside:

- `assets` directory: this contains the image assets I exported from the Figma file, renamed, and optimized before uploading to my AWS S3 bucket for hosting.
- `components` directory: these are the individual components taken from the `full-email.html` file; these could be used as Content Blocks in Braze.
- `full-email.html`: this is the fully built email based on the Figma design.
