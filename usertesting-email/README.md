# UserTesting Email Samples

![UserTesting Image](/assets/ut-homepage-thumbnail.jpeg)

A production-ready Marketo Engage email template system built for UserTesting, covering external marketing, partner newsletters, and internal employee communications. Templates share a common module library and brand system, allowing non-technical marketers to compose emails via Marketo's drag-and-drop editor without touching code. I also enhanced the Marketo email preference center's UX to align with the new brand identity.
