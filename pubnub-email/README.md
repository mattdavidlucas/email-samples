# PubNub Email Templates

At PubNub, I helped redesign their existing email templates by incorporating brand elements from their website into a cohesive, on-brand email design system. Beyond the design refresh, I also built out a custom PHP-based build system to streamline the entire email production process — using includes and variables to eliminate repetitive boilerplate, encoding strings of text, outputting static HTML files, and leveraging PHP's for loops to dynamically echo JSON content for newsletters.

It was a practical solution that punched well above its weight: suddenly, updating a global header or footer meant editing one file instead of a dozen, and spinning up a new newsletter template was a matter of configuring a few variables rather than copy-pasting code. Sometimes the old-school tools are the right ones for the job.
