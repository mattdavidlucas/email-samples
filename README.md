# Work Samples

## What's in this repo:

- **`pierry-email`** (Pierry Software): Reusable templates and AMPScript-driven dynamic content built across a multi-client roster at a Salesforce Marketing Cloud agency.

- **`pubnub-email`** (PubNub): A custom PHP-based build system using includes, variables, and loops that eliminated manual and repetitive work, and kept all digital marketing assets on brand. Updating a global header meant editing one file instead of a dozen, long before that workflow felt routine.

- **`teradata-ozone-samples`** (Ozone Online & Teradata): Agency-side front-end work across enterprise clients and platforms, including a fully documented email design system and content component library with wireframes, a style guide, and annotated examples.

- **`usertesting-email`** (UserTesting): A Marketo Engage template system with a shared module and brand library that let non-technical marketers build emails by drag-and-drop, plus UX work on the email preference center.
