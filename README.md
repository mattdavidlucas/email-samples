## Hi there, my name is Matthew Lucas.

I'm a front-end email developer and marketing technologist based in Charlotte, North Carolina. This repository is a collection of code samples from my career — HTML emails, template systems, and front-end assets spanning about a decade of work across agencies, SaaS companies, and fintech.

The work here covers everything from hand-coded transactional emails and multi-client agency builds, to full email design systems, Liquid-powered personalization layers, and PHP-based build tooling I put together long before AI made that sort of thing feel routine. Each folder corresponds to a specific role or employer, with its own README that provides context on the work.

If you have questions about anything you see here, feel free to reach out on [LinkedIn](https://www.linkedin.com/in/mattdavidlucas/), or find me in the [Email Geeks](https://emailgeeks.slack.com/) Slack community — I'm @mattdavidlucas.
