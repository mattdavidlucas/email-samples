# Work Samples

An archive of production email and landing page work from various roles. Some of it is straightforward client delivery; some of it is the template systems and build tools I put underneath that delivery so it stopped being manual. Each directory has its own README with the details.

## What's in this repo

- **[`usertesting-email`](usertesting-email/)** (UserTesting, 2020 to 2022): A Marketo Engage template system with a shared module library and brand system that let non-technical marketers build emails by drag-and-drop, plus the email preference center.

- **[`pierry-email`](pierry-email/)** (Pierry Software, 2016): Reusable Salesforce Marketing Cloud templates and AMPScript-driven dynamic content built across a multi-client roster at a boutique SFMC agency.

- **[`teradata-ozone-samples`](teradata-ozone-samples/)** (Ozone Online & Teradata, 2013 to 2016): Agency-side front-end work for Autodesk, Intel, Hertz, and Teradata's own DMP demos. Includes two build tools I wrote so the team stopped hand-producing assets: a PHP component library for Autodesk emails, and a browser-based generator for Intel's Internet of Things nurture program.
