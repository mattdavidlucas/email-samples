# Hi there, my name is Matthew Lucas.

I'm a marketing technologist and systems engineer based in Charlotte, North Carolina, working where marketing operations meets AI enablement. I build the systems that make marketing teams faster: modular template architectures, personalization layers, build tooling, and the AI-assisted workflows that tie them together.

This repository is the proof. It's about a decade of production code from agencies, SaaS companies, and fintech, and it shows how I think about scale, maintainability, and turning repetitive manual work into systems other people can actually use. A lot of it happens to be email, because that's where I spent years solving these problems; but the through-line is systems design, not any single channel.

Each directory below maps to a specific role or engagement and has its own README with deeper context.

## What's in this repo

- **`ck-braze-emails`** (Credit Karma): A Liquid template system I rebuilt from scratch during a migration off Handlebars to Braze.

- **`ck-email-module-samples`** (Credit Karma): A sampling of modules I coded using Cursor and Figma's MCP. They're here because the AI-assisted tooling cut development time on a production template system considerably.

- **`lendingtree-email`** (LendingTree): A Liquid-powered template system deployed from Blueshift, plus the codebase modernization behind it (version control, refactored legacy templates, a more maintainable foundation). Some of this work was featured on Really Good Emails and in a Litmus case study.

- **`pierry-email`** (Pierry Software): Reusable templates and AMPScript-driven dynamic content built across a multi-client roster at a Salesforce Marketing Cloud agency.

- **`pubnub-email`** (PubNub): A custom PHP-based build system using includes, variables, and loops that eliminated manual and repetitive work, and kept all digital marketing assets on brand. Updating a global header meant editing one file instead of a dozen, long before that workflow felt routine.

- **`teradata-ozone-samples`** (Ozone Online & Teradata): Agency-side front-end work across enterprise clients and platforms, including a fully documented email design system and content component library with wireframes, a style guide, and annotated examples.

- **`usertesting-email`** (UserTesting): A Marketo Engage template system with a shared module and brand library that let non-technical marketers build emails by drag-and-drop, plus UX work on the email preference center.
